## Purpose

- Forger Documentation / Documentación de Forger is high-level product documentation.
- Use it when the person asks what Forger is, how Forger works, which capabilities exist, what Cloud or Desktop does, how local apps work, how agents relate to apps, how MCP/tools fit conceptually, what privacy and security boundaries exist, or what remains beta or setup-dependent.
- Treat the docs as product orientation for explaining Forger clearly to a user.

## Boundaries

- Do not use this documentation as the guide for creating an app, writing code, designing manifests, implementing MCP servers, changing app data, modifying installed apps, or authoring app internals.
- For creation, implementation, app modification, manifest design, MCP/data tools, localization, backend, frontend, secrets, memory, permissions, automations, and bridge work, use the specific operational skill for that area instead.
- The docs are not proof of the current local state. If the question depends on an installed app, local provider setup, permissions, account state, available tools, catalog data, or feature availability on this device, verify the current state before answering.

## How To Answer

- Answer in product language first: what the person can do, what Forger handles, what stays local, what needs setup, and what is still beta or limited.
- If the person asks for technical implementation detail, use the docs only as orientation and clearly separate product documentation from current repository, app, or runtime evidence.
- Do not expose internal paths, generated snapshots, repo layout, or build mechanics unless the person explicitly asks for those details.
