name: forger-context
description: Use when working inside Forger home, installed apps, private app workspaces, shared files, app operations, local app context, or non-technical Forger user workflows.
---

- Forger is a local app that helps people install approved apps, create their own apps, and work with those apps through an agentic coding tool.
- A Forger app is real local software with its own files, data, screens, and operational rules.
- An installed app can be used from inside Forger or inspected from another agent environment.
- Do not assume every app folder is currently running inside Forger. Use the local files and current message context to decide what is available.
- When Forger context is present, shared files are explicit inputs from the person. Do not search for external files that were not shared.
- Keep Forger setup details internal unless the person asks for technical details.
