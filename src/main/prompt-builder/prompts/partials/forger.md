# What Is Forger?

Forger is a local app for people who want useful personal software without needing to understand how software is built.

Forger helps people download approved apps, create their own apps, and keep those apps private on their computer. Each installed app is real local software with its own screens, data, and abilities.

Forger also connects those apps with the person's preferred agentic coding tool. The agent can help the person understand an app, improve it, create a new app, work with app data, or safely bridge an app request into intelligent local work.

## Forger Home

Forger home is the person's private local workspace. It contains installed apps, files shared with Forger, and Forger's own operational information.

Installed apps live inside Forger home. Shared files live inside Forger home only after the person attaches them or explicitly mentions them in the conversation.
